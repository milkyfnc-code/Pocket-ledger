# Pocket Ledger PWA — คู่มือติดตั้งบน iPhone

## สิ่งที่มีในชุดนี้
- `index.html`, `styles.css`, `app.js` — ตัวแอป
- `manifest.webmanifest` — ข้อมูลสำหรับ Add to Home Screen
- `service-worker.js` — แคชไฟล์เพื่อเปิดออฟไลน์
- `icons/` — ไอคอนแอป

## ข้อกำหนดสำคัญ
PWA ต้องเปิดผ่านเว็บไซต์ **HTTPS** (หรือ localhost สำหรับทดสอบ) จึงจะติดตั้ง Service Worker และใช้งานออฟไลน์ได้ อย่าเปิด `index.html` จากแอป Files โดยตรงแล้วคาดหวังว่า PWA จะทำงานครบ

## วิธีนำขึ้นเว็บไซต์แบบง่าย
1. สร้างบัญชี GitHub และสร้าง repository ใหม่ เช่น `pocket-ledger`.
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้เข้า repository โดยให้ `index.html` อยู่ที่ root.
3. ใน repository ไปที่ **Settings → Pages**.
4. เลือก **Deploy from a branch**, เลือก branch `main` และ folder `/(root)` แล้ว Save.
5. รอ GitHub Pages เผยแพร่เว็บไซต์ HTTPS จากนั้นเปิด URL ที่ GitHub Pages แสดง

หากทำทุกอย่างจาก iPhone ให้แตก ZIP ในแอป Files แล้วใช้ Safari เปิด GitHub เพื่ออัปโหลดไฟล์ทีละชุด หรือใช้คอมพิวเตอร์ช่วยอัปโหลดจะสะดวกกว่า

## ติดตั้งบน iPhone
1. เปิด URL เว็บไซต์ด้วย Safari (ไม่ใช่เบราว์เซอร์ในแอปอื่น).
2. แตะปุ่ม Share.
3. เลือก **Add to Home Screen**.
4. หากมีตัวเลือก **Open as Web App** ให้เปิดไว้ แล้วแตะ Add.
5. เปิด Pocket Ledger จากไอคอนบน Home Screen และเปิดค้างไว้สักครู่เพื่อให้ Service Worker แคชไฟล์ครบ

ชื่อเมนูอาจต่างกันเล็กน้อยตามเวอร์ชัน iOS

## วิธีใช้
- ภาพรวม: ยอดรวมเป็น THB และยอดคงเหลือแต่ละสกุลเงิน
- เพิ่มรายการ: กดปุ่ม `+`, เลือกรายรับ/รายจ่าย, จำนวน, สกุลเงิน, หมวดหมู่, วันที่
- สกุลเงิน: แก้เรทหรือเพิ่มสกุลเงินใหม่
- สำรองข้อมูล: ดาวน์โหลด JSON เป็นไฟล์หลักสำหรับสำรอง/กู้คืน และ CSV สำหรับเปิดใน Excel

เรทเริ่มต้น USD 35, JPY 0.23, EUR 38 เป็นเพียงตัวอย่าง ต้องแก้เป็นเรทที่คุณต้องการใช้เอง

## สำรองข้อมูลและความเป็นส่วนตัว
ข้อมูลอยู่ใน localStorage ของเว็บไซต์บนอุปกรณ์นี้ ไม่ถูกส่งไปยังเซิร์ฟเวอร์โดยโค้ดแอปนี้ แต่ข้อมูลอาจหายได้เมื่อเคลียร์ข้อมูลเว็บไซต์/ประวัติและข้อมูลเว็บไซต์ หรือเปลี่ยนโดเมน/เบราว์เซอร์ จึงควร Export JSON เป็นประจำ และทดสอบ Import จากไฟล์สำรอง

การเปิด PWA แบบ standalone และ Safari อาจใช้พื้นที่จัดเก็บของเว็บไซต์ร่วมกันหรือแยกกันตามพฤติกรรม iOS; ควรใช้งานจากไอคอนเดียวกันและสำรองไฟล์ไว้เสมอ

## ขอบเขตเวอร์ชันนี้
- เพิ่มและลบรายการ (ยังไม่มีแก้ไขรายการเดิม)
- ยอดแยกสกุลเงินและยอดรวม THB
- เรท snapshot ต่อรายการ
- เพิ่ม/ลบสกุลเงิน (ลบไม่ได้หากมีรายการอ้างอิง)
- Backup/Restore JSON และ Export CSV
- ไม่มีรหัสผ่าน/Face ID และไม่มี cloud sync
