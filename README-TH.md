# Pocket Ledger PWA v2
แอปบันทึกการเงินส่วนตัวหลายสกุลเงิน ใช้บน iPhone ผ่าน Safari > Add to Home Screen

## ฟังก์ชัน
- เพิ่มสกุลเงินเอง พร้อมเรทซื้อและเรทขายแยกกัน (หน่วย THB ต่อ 1 หน่วยเงินตรา)
- เพิ่มกระเป๋าเงินได้หลายใบ เช่น เงินสด บัญชีธนาคาร เงินสดต่างประเทศ
- รายรับ รายจ่าย และโอน/แลกเงินระหว่างกระเป๋าหรือสกุลเงิน
- รายการแลกเงินเก็บจำนวนจ่าย จำนวนรับ และเรทจริงที่คำนวณจากสองยอด
- ยอดคงเหลือแยกตามสกุลเงินและกระเป๋า พร้อมมูลค่ารวม THB
- ค้นหา แก้ไข และลบรายการย้อนหลัง
- สำรอง/นำเข้าข้อมูล JSON และส่งออก CSV

## ข้อควรทราบ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่มี cloud sync; สำรอง JSON เป็นประจำ
- แอปใช้เรทซื้อกับรายการรายรับ และเรทขายกับรายการรายจ่ายเพื่อประเมินมูลค่า THB
- มูลค่ารวมใช้เรทซื้อเมื่อยอดสกุลเงินเป็นบวก และเรทขายเมื่อยอดติดลบ เป็นมุมมองประมาณการ ไม่ใช่มูลค่ารับประกันว่าจะแลกได้จริง
- การโอน/แลกเงินให้กรอกยอดจ่ายและยอดรับตามหลักฐานจริง เรทจริงจึงไม่ขึ้นกับเรทตั้งต้น
- อัปโหลดไฟล์ทั้งหมดไปยัง GitHub Pages แล้วเปิด URL แบบ HTTPS ก่อนติดตั้ง PWA
